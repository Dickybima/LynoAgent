LYNOAGENT
Beranda Tools Instalasi Cara Kerja

Instalasi

Build sekali, lalu sambungkan ke klien MCP favorit Anda.

1

Build server

cd server
npm install
npm run build
2

Sambungkan ke klien

Tambahkan ke claude_desktop_config.json:

{
  "mcpServers": {
    "lyno-agent": {
      "command": "node",
      "args": ["/path/ke/LynoAgent/server/dist/index.js"],
      "env": { "LYNO_WORKSPACE": "/path/ke/project-anda" }
    }
  }
}
claude mcp add lyno-agent \
  -e LYNO_WORKSPACE=$(pwd) \
  -- node /path/ke/LynoAgent/server/dist/index.js

Jalankan endpoint Streamable HTTP di /mcp:

node server/dist/index.js --http --port 3333
# → http://127.0.0.1:3333/mcp   (cek: /health)
3

Konfigurasi (opsional)

LYNO_WORKSPACEFolder yang boleh diakses tool file (default: folder saat ini)
LYNO_DATA_DIRLokasi penyimpanan memori (default: ~/.lyno-agent)
LYNO_READ_ONLYIsi 1 untuk mematikan semua aksi tulis
