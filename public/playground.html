This is the live Lyno Agent MCP server. Connect it to Claude, or call its tools right here from your browser.

Connect

Open Settings → Connectors → Add custom connector, name it Lyno Agent and paste the URL:

https://www.lynoagent.com/mcp
claude mcp add --transport http lyno-agent https://www.lynoagent.com/mcp

For clients that accept a remote MCP server URL (Cursor, VS Code, MCP Inspector…):

{
  "mcpServers": {
    "lyno-agent": { "url": "https://www.lynoagent.com/mcp" }
  }
}

The hosted endpoint runs the web and utility tools. File and memory tools need your machine, so they only run when you install Lyno locally (see Install).
