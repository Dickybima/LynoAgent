MCP One plug. Your AI sees the chain.

MCP — the Model Context Protocol — is the open standard that lets AI apps call outside tools. Lyno speaks it, so any MCP client can use Lyno's Elysium scanner as if it were built in.

  1. 01

    Connect

    Paste one URL into Claude, Cursor or VS Code. No API key, no wallet, no install.

  2. 02

    Ask

    Talk like you normally would: “Is this token safe?” “Who's really holding it?”

  3. 03

    Lyno reads the chain

    Your AI calls token_info. Lyno pulls the Elysium data and hands back the facts in seconds — your AI explains them.
