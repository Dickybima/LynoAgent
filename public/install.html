Install

Build once, then connect it to your favorite MCP client.

No install needed for the web and utility tools: connect Claude to the hosted endpoint from the Playground. Install locally to also get file and memory tools.

1

Build server

cd server
npm install
npm run build
2

Connect a client

Add this to claude_desktop_config.json:

{
  "mcpServers": {
    "lyno-agent": {
      "command": "node",
      "args": ["/path/to/LynoAgent/server/dist/index.js"],
      "env": { "LYNO_WORKSPACE": "/path/to/your-project" }
    }
  }
}
claude mcp add lyno-agent \
  -e LYNO_WORKSPACE=$(pwd) \
  -- node /path/to/LynoAgent/server/dist/index.js

Run a Streamable HTTP endpoint at /mcp:

node server/dist/index.js --http --port 3333
# → http://127.0.0.1:3333/mcp   (check: /health)
3

Configuration (optional)

LYNO_WORKSPACEFolder the file tools may access (default: current directory)
LYNO_DATA_DIRWhere memory is stored (default: ~/.lyno-agent)
LYNO_READ_ONLYSet to 1 to disable all write actions
